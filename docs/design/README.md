# 食刻前端视觉说明

## 方向

界面采用克制的中文编辑式餐食工具风格：真白与浅灰为底，墨色文字，陶瓷绿作为结构色，少量橙色用于主要动作。标题使用中文衬线字体，正文使用系统无衬线字体。页面保持开放留白，以分隔线、列表和窄侧栏组织信息，不使用渐变光球、聊天机器人头像或同尺寸卡片阵列。

## 概念图

- `main-workspace-concept.png`：主推荐工作台
- `model-settings-concept.png`：模型设置页

## ImageGen 提示词摘要

概念图提示词要求绘制 1440×960 的高保真桌面网页：品牌为“食刻”，左侧窄导航，中央开放式中文餐食对话，右侧轻量推荐栏；设置页沿用相同视觉语言，以三个带编号的横向章节组织厂商、接口与模型。明确排除蓝紫渐变、悬浮玻璃卡、机器人拟人形象和营销仪表盘式布局。

三张餐食图分别要求自然窗光下的番茄鸡蛋面、清汤馄饨和鸡胸肉轻食碗，编辑杂志式真实食物摄影，俯拍略带侧角度，中性陶瓷餐具与安静桌面，不含文字、人物、品牌标识和夸张商业高光。
